# ImproClean

**Smart Monitoring System for Predicting Microbiological Load in Commercial Laundries**

This project focuses on predicting microbiological load in commercial laundries using machine learning. The core models and data transformation pipelines are designed to provide accurate predictions based on various measurements.

## Project Highlights

- **Ensemble Models:** XGBoost combined with Random Forest for high-accuracy predictions.
- **Data Transformation:** Comprehensive pipeline for selecting, cleaning, and preparing data.
- **Automation:** Automated workflows for training, prediction, and monitoring.
- **SQL Integration:** Software designed to pull data from and push predictions back to SQL databases.
